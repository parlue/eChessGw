eChessGw

BLE gateway for ChessLink chess computer modules -- multi-board, standalone mode, automatic PGN recording

eChessGw bridges a cable-connected chess computer module (MILLENNIUM King, Mephisto Phoenix) to any of several wireless e-boards over BLE -- one firmware, automatic board detection at runtime. With no cable computer present, the gateway can also masquerade as a ChessLink or Chessnut board itself, so wireless chess software can connect directly.

  • Supported e-boards: MILLENNIUM Supreme T2 BT, Chessnut Air/GO/Pro, Certabo and Tabutronic Spectrum (setup below), ManyaCynus camera-vision robot (including castling, en passant, promotion)
  • Standalone mode: no cable computer needed -- the gateway advertises itself as a ChessLink or Chessnut board over BLE for wireless chess software (PicoChess, BearChess, Chess PGN Master)
  • Automatic PGN game recording, including checkmate detection and a manual result-signal gesture
  • USB game retrieval via a simple physical gesture and a standalone Windows tool
  • Flash directly from your browser -- no toolchain required (below)

Stable release — V12

Tester-confirmed Certabo / Spectrum release. ESP32-C3 SuperMini.

Certabo / Spectrum setup

Use the normal 32-piece starting position plus two extra queens:

  • Certabo: white extra queen on d3, black extra queen on d6.
  • Spectrum: white extra queen on e3, black extra queen on e6.

Keep the pieces still. One stable extra queen enables setup assistance; all 34 unique chips must be learned before completion. The four centre squares blink three times. Then remove both extra queens when their squares light up. Normal play starts only with the correct 32-piece starting position. IDs are learned anew on every connection.

Spectrum uses blue at 80% brightness by default. Colour and brightness gestures remain available.

Installation

  1. Connect the ESP32-C3 SuperMini to your computer via USB.
  2. Use Google Chrome or Microsoft Edge.
  3. Click Connect above.
  4. Select the ESP32-C3 serial device.
  5. Confirm the installation and wait until flashing is complete.
  6. Disconnect and reconnect USB power.

Target: ESP32-C3 SuperMini compatible boards
