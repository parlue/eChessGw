eChessGw

BLE gateway for ChessLink chess computer modules -- multi-board, standalone mode, automatic PGN recording

eChessGw bridges a cable-connected chess computer module (MILLENNIUM King, Mephisto Phoenix) to any of several wireless e-boards over BLE -- one firmware, automatic board detection at runtime. With no cable computer present, the gateway can also masquerade as a ChessLink or Chessnut board itself, so wireless chess software can connect directly.

  • Supported e-boards: MILLENNIUM Supreme T2 BT, Chessnut Air/GO/Pro, Certabo (pieces are read in at every start: 32 pieces in the starting position plus a spare white queen on d3 and a spare black queen on d6; the four centre squares blink three times when done, then remove the two queens), ManyaCynus camera-vision robot (including castling, en passant, promotion)
  • Standalone mode: no cable computer needed -- the gateway advertises itself as a ChessLink or Chessnut board over BLE for wireless chess software (PicoChess, BearChess, Chess PGN Master)
  • Automatic PGN game recording, including checkmate detection and a manual result-signal gesture
  • USB game retrieval via a simple physical gesture and a standalone Windows tool
  • Flash directly from your browser -- no toolchain required (below)

Stable release — v11

Recommended for normal use. ESP32-C3 SuperMini.

Beta: Certabo / Spectrum — 2026-10-27 / Queen setup

Test firmware for ESP32-C3 SuperMini. Select the correct LED driver through the extra queens, not through chip IDs or BLE packet sizes.

  • Certabo: normal starting position + white extra queen d3, black d6.
  • Spectrum: normal starting position + white extra queen e3, black e6.

No setup LEDs until all 34 figures are learned. Keep the position still for seven scans. The four centre squares then blink three times (Spectrum: blue 80%). Remove both extra queens when prompted.

Spectrum play defaults to blue 80%; saved gesture settings remain available. MTU stays 256. Physical testing remains required; no freeze yet.

Scope: corrects LED-driver selection and the learning gate; it is not a confirmed fix for radio-level failures before connection.

Installation

  1. Connect the ESP32-C3 SuperMini to your computer via USB.
  2. Use Google Chrome or Microsoft Edge.
  3. Click Connect above.
  4. Select the ESP32-C3 serial device.
  5. Confirm the installation and wait until flashing is complete.
  6. Disconnect and reconnect USB power.

Target: ESP32-C3 SuperMini compatible boards
